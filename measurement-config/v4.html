Inspection workflow — measurement steps Mockup v4 — for review

The measurement part of one inspection workflow. Each step is a group of measurements the inspector performs; the list on the left is the order they happen in. A step either measures every POM in a Measurement Chart, or defines its own values by hand.

The two axes — independent of each other
Specification — where the standard value and tolerance bands come from. Measurement Chart means every POM in the chart is measured, each carrying its own unit, standard value and tolerance. Manual means you set the unit and the criteria here.
Value — where the number comes from. Either the inspector enters it, or a formula computes it from other values in the same step.

Changed from v3: the specification comes from a Measurement Chart, not a single POM — so there is no unit at chart level, only inside each POM. And these are ordered steps in one workflow, not reusable templates: the left column is the inspection sequence and is drag-reorderable.
