Inspection check configuration Mockup v2 — for review

Admins define the values taken per sample and the acceptance criteria for each, in one place. Standard values and tolerances for each specification are still pulled automatically from the spec sheet and are not configured here.

What changed from v1
  • One row type and one + Add value button. A formula is an attribute of a value, not a separate kind of row.
  • Source, specification type and unit collapsed into one paired control — Value from — since they answer the same question.
  • One evaluation list for every row, always optional. Against specification tolerance appears only when the value is spec-linked.
  • Evaluation collapses to a summary line; defaults mean most rows never need it opened.
  • Formulas can reference other formula rows, and an intermediate formula row can now be left unevaluated (see Fabric weight). Cycles are blocked at the operand picker.

Check types

Sampling rule — how many samples are pulled before measuring, same options for every check type

Values — each value is taken from a specification, entered manually, or calculated from other values

Drag the handle on a row to reorder it. Formulas reference other values by name, so order never affects which value feeds a formula — it is only for reading top to bottom.
