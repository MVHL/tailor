Check template configuration Mockup v3.2 — for review

A check template is a reusable definition of one way to take measurements — the values taken per sample and the acceptance criteria for each. Templates are added to an inspection workflow, in whatever order that workflow needs. Ordering happens there, not here.

The two axes — independent of each other
Specification — where the standard value, unit and tolerance bands come from. Choosing POM means the POM already records all three. Manual means you set the unit and the criteria here.
Value — where the number comes from. Either the inspector enters it, or a formula computes it from other values in this check.

Changed from v2: v2 treated these as one control and called it “Value from”, which forced a formula and a POM-backed value to be mutually exclusive. They are not — see Average weight, where a formula result is checked against a Weight POM’s tolerance bands.
