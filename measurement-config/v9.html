Inspection workflow — measurement steps Mockup v9 — for review

The measurement part of one inspection workflow. Each step is a group of measurements the inspector performs; the list on the left is the order they happen in. A step either measures every POM in a Measurement Chart, or defines its own values by hand.

Rows are columns. The step says how many times each one is filled.
Measurement Chart step — every row is filled once per POM, for every sample. So a step can measure Before wash and After wash per POM and derive a shrinkage per POM: the formula runs once for each POM, because the whole step shares one cardinality.
Custom values step — every row is filled once per sample. Same row structure, same formulas, same evaluation. Only the number of times each column gets filled differs.

Changed from v8: v8 concluded a chart step has no values at all, which made shrinkage-per-POM impossible. The cardinality belongs to the step, and the rows are uniform within it — that is what v7 got wrong in the other direction, by letting some rows be per-POM and others single inside one step. A row still defers to its POM’s own tolerance only when it is that POM’s measurement: a derived shrinkage is not comparable to a tolerance expressed in cm.
