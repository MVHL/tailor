# Runs index

Running log of every orchestrated task in this repo — newest last. Mirrors the
`measurement-config` changelog convention: a scannable "what happened / why" table that
is the entry point to the per-run records. The Phase-2 dashboard reads the `RECORD.md`
frontmatter behind these rows.
